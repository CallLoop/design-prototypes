# design-prototypes

Design concepts and clickable prototypes for **Call Loop**, kept in one place so they're easy to share with the team via a link.

Each prototype is a single self-contained HTML file — no build step, no dependencies. Open it in a browser and click around.

## Prototypes

| Prototype | File | What it covers |
|---|---|---|
| Analytics | [CallLoop-Analytics-Prototype.html](CallLoop-Analytics-Prototype.html) | Analytics / reporting screens |
| Buy number | [CallLoop-BuyNumber-Prototype.html](CallLoop-BuyNumber-Prototype.html) | Flow for buying a phone number |
| ClickBank integration | [CallLoop-ClickBank-Prototype.html](CallLoop-ClickBank-Prototype.html) | Connecting and using the ClickBank integration |

## Viewing a prototype

- **Locally:** clone the repo (or download the file) and open the `.html` file in your browser.
- **Sharing:** send a teammate the link to the file in this repo. They need access to the `CallLoop` organization, since the repo is private.

## Adding a new prototype

1. Export or save the prototype as a single `.html` file.
2. Name it `CallLoop-<Feature>-Prototype.html`.
3. Add a row to the table above.
4. Commit and push to `main`.
